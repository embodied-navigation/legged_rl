# H2 Sim2Sim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将官方 `unitree_mujoco` 作为第三个工作区子模块，在笔记本 MuJoCo 3.3.6 中通过 C++/Unitree SDK2/DDS 部署链路验证 `unitree_rl_lab` 训练出的 H2 15-DoF 强化学习速度步态策略。

**Architecture:** 团队 fork 固定官方已有的完整 H2 31-motor MJCF 和 `unitree_hg` simulator bridge；`unitree_rl_lab/deploy/robots/h2` 复用现有 FSM、ONNX Runtime、observation/action manager，仅让策略控制腿部与腰部 15 个关节，其余关节 PD 保姿。训练服务器负责导出 ONNX 与 `deploy.yaml`，笔记本只负责编译 controller、运行 MuJoCo GUI 和采集 sim2sim 指标。

**Tech Stack:** C++17、CMake、MuJoCo 3.3.6、Unitree SDK2、CycloneDDS、ONNX Runtime 1.22、yaml-cpp、Eigen、Boost、Python 3、pytest、Git submodule

**Design:** `docs/superpowers/specs/2026-07-21-h2-sim2sim-design.md`

**执行状态（2026-07-22）：** 功能实现、静态测试、两侧 C++ 编译、ONNX 导出同步、GUI/FixedStand/Policy 烟雾测试和固定八场景回归均已执行。正式策略至少两轮完成 80 秒序列，但结果不稳定：另两轮在右侧移约 42 秒时触发 `right_ankle_roll_joint` 硬下限；因此不能判定硬性验收稳定通过。通过轮 `2026-07-22_formal_2` 的序列结束时无 NaN、DDS 超时、软/硬限位、pelvis/torso 或非足部地面接触。后续需优化右踝稳定性并重复验收。真实机器人验证未运行。

所有 PD、mode 和 motor index 必须引用官方 H2 定义或模型数据；无来源时先使用保守仿真值并在配置中明确标注，不宣称为实机参数。
