# legged_rl

Integration workspace for learning, training, and deploying legged robot reinforcement learning projects.

## Modules

- `modules/unitree_rl_lab`: Fork of [unitreerobotics/unitree_rl_lab](https://github.com/unitreerobotics/unitree_rl_lab), based on Isaac Lab.

## Clone

```bash
git clone --recurse-submodules git@github.com:embodied-navigation/legged_rl.git
```

For an existing clone:

```bash
git submodule update --init --recursive
```
